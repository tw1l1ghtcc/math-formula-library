数学公式查询程序 · 公式集

打开方法
下载“index.html”，用 Edge、Chrome 等现代浏览器打开即可。
无需安装，无需联网，无需账号。

主要功能
1. 查询：搜索公式名称、内容、标签和说明，支持用空格分隔多个关键词。
2. 分类：先选择高等数学、线性代数、概率统计，再按章节筛选；保留基础数学。
3. 收藏：点击公式卡片右上角的星标，在“我的收藏”中查看。
4. 添加：点击“添加公式”，填写名称、分类、公式内容及说明。
   分类可以输入新名称，后续会自动出现在分类列表。
5. 编辑：进入“查看详情”，点击“编辑公式”。
6. 删除与恢复：详情页可以删除；点击提示中的“撤销”，或在
   “使用指南与数据说明 → 撤销删除”中恢复。
7. 备份：点击左侧“导出备份”，保存下载的 JSON 文件。
8. 导入：点击“导入公式”，选择本程序导出的 JSON 文件并确认。
   同编号公式会被更新，其他公式保留，收藏合并。

公式输入
支持数学公式（LaTeX）和普通文本两种输入方式，并有实时数学排版预览。
点击分数、根号、积分、求和等模板按钮插入结构，再修改其中的字母。
例如：a² + b² = c²、S = πr²、x = (−b ± √(b² − 4ac)) / (2a)。
数学公式模式支持 LaTeX，例如 \frac{a}{b}、\sqrt{x}、x^{n}、\sum_{k=1}^{n}a_k。
普通文本模式可继续使用 a²、√(x)、a/b 等写法，并尽可能排成数学格式。
当前版本用于查询和编辑，不自动计算公式结果。

数据保存
数据保存在当前浏览器的本地存储中，不自动跨设备或跨浏览器同步。
尽量在同一个浏览器中打开同一位置的 HTML 文件。
移动文件、改名、清理浏览器数据、使用无痕模式等可能导致旧记录不可见。
请定期导出备份；换电脑或换浏览器时，打开程序并导入备份即可。
如果页面提示存储不可用，请先导出备份，再关闭页面。

内置 425 条公式、定理与判定条件，覆盖数学一高数8章、线代6章、概率统计8章，支持保存最多 5000 条有效公式。

新增泰勒展开、柯西中值定理、柯西不等式、极限、导数、积分、级数、

更新方式
1. 继续在原位置打开新版 HTML，会自动补入新增公式，保留旧数据。
2. 若继续使用旧版程序，导入“高数公式补充包.json”即可补入 100 条内容。
3. 若换了文件位置或浏览器，先在旧程序导出备份，再在新程序导入。

数学排版版
全部内置公式均采用标准数学排版，字体和排版组件嵌入 HTML，仍可离线使用。
打开同一路径的新版文件即可看到新排版，旧公式内容和收藏无需重新输入。
长公式可在公式区域左右滑动查看；点击详情可在更宽的区域阅读。
若改过某条内置公式，新版会保留修改，可进入编辑窗口选择输入方式。

排版组件：KaTeX 0.18.7（MIT 许可），许可信息已包含于 HTML 文件中。
https://katex.org/docs/browser
