使用指南

查询：按名称、公式内容、标签或说明搜索；多个关键词用空格分隔。可先选择高数、线代或概率统计，再按章节筛选；科目、分类和收藏筛选可以与搜索一起使用。

积累：点击“添加公式”录入知识。分类可以直接输入新名称；公式支持数学排版和普通文本两种输入方式，模板按钮可快速插入分数、根号、积分和求和结构。星标用于收藏，详情页可以编辑、复制和删除。复制内置公式会得到可用于数学公式模式的 LaTeX 文本；长公式可左右滑动查看。

备份：“导出备份”会下载 JSON 文件，包括完整公式库和收藏。导入时按公式编号合并，同编号使用备份中的内容，其他公式保留。导入前会显示数量供你确认。

保存：所有数据只保存在当前设备、当前浏览器中，不会自动同步。移动或改名 HTML 文件、换浏览器、清理浏览器数据或使用无痕模式可能使原来的记录不可见。操作前请导出备份。

预置公式：包含 425 条公式、定理与判定条件，覆盖数学一各章并保留基础数学。可编辑；删除后不会在刷新时重新出现。每次删除都可从提示条撤销，也可在撤销删除面板中恢复。
