# 数学公式查询

一个可以离线使用、后续自行添加公式的数学公式查询程序。内置 **425 条公式、定理和判定条件**，按考研数学一的高等数学、线性代数、概率统计章节整理，并保留基础数学内容。

## 使用方法

### 1. 下载并打开

1. 在仓库首页点击绿色 **Code** 按钮，选择 **Download ZIP**。[GitHub 下载说明](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives)
2. 将下载的 ZIP 压缩包解压到一个固定文件夹，例如“文档/数学公式查询”。
3. 在解压后的文件夹中找到 `index.html`，双击，或右键选择“打开方式 → Microsoft Edge / Google Chrome”。
4. 页面出现公式列表后即可使用。无需安装、联网或注册程序账号，数学排版组件和字体已包含在页面中。

也可以直接[下载整个项目](https://github.com/tw1l1ghtcc/math-formula-library/archive/refs/heads/main.zip)，然后按上述步骤解压、打开。

GitHub 中的 `index.html` 文件页面用于查看源码；使用程序需要将文件下载到电脑并在浏览器中打开。

### 2. 查询与收藏公式

- 在搜索框输入名称或关键词，例如“泰勒”“柯西”“行列式”“正态分布”。
- 多个关键词用空格分隔，查询结果需要同时匹配这些关键词。
- 先选择科目，再按章节筛选，方便按数学一考点查找。
- 点击公式的“查看详情”，阅读适用条件、符号说明和例题。
- 点击公式卡片右上角的星标收藏，在“我的收藏”中查看。

### 3. 添加和编辑公式

1. 点击“添加公式”。
2. 填写公式名称、分类、公式内容和说明；分类可以输入新名称。
3. 选择数学公式（LaTeX）或普通文本输入方式。可点击分数、根号、积分、求和等模板按钮，并查看实时排版预览。
4. 填写适用条件、符号含义、例题和标签，方便后续检索。
5. 点击“保存公式”。

要修改已有公式，进入“查看详情 → 编辑公式”，修改后保存。

常用 LaTeX 写法：

| 内容 | 输入示例 |
| --- | --- |
| 分数 | `\frac{a}{b}` |
| 根号 | `\sqrt{x}` |
| 幂 | `x^{n}` |
| 定积分 | `\int_a^b f(x)\,dx` |
| 求和 | `\sum_{k=1}^{n}a_k` |

在数学公式输入框中直接填写这些内容，无需加美元符号。普通文本模式也支持 `a² + b² = c²`、`√(x)` 等写法。

### 4. 删除和恢复

在公式详情页删除公式后，可点击提示中的“撤销”；也可以在“使用指南与数据说明 → 撤销删除”中恢复。

### 5. 备份与换设备

1. 点击左侧“导出备份”，保存下载的 JSON 文件。
2. 换电脑、换浏览器或移动程序文件前，先导出备份。
3. 在新的位置打开程序，点击“导入公式”，选择备份 JSON 文件，检查导入信息后确认。
4. 同编号公式会被更新，其他公式保留，收藏合并。

个人公式保存在当前浏览器中，不会自动同步到 GitHub。请尽量使用同一个浏览器、同一文件位置；清理浏览器数据或使用无痕模式可能使旧记录不可见。若页面提示存储不可用，请先导出备份再关闭页面。

### 6. 更新程序

先导出备份，再下载新版项目，将新版 `index.html` 放回原来的文件位置，并用原浏览器打开。程序会自动补入新增条目，并保留用户编辑、收藏和删除记录；如旧数据不可见，可导入之前保存的备份。

当前版本已包含仓库内两个补充包的内容，无需重复导入。

## 功能

- 按名称、公式、标签、说明、符号和例题搜索，支持多个关键词。
- 按科目和章节筛选，收藏常用公式。
- 添加、编辑、删除和恢复公式，自定义分类。
- 支持 LaTeX 数学字体、输入模板和实时预览。
- 导入、导出 JSON 备份，最多保存 5000 条有效公式。
- 新版自动补入新增内容，并保留用户编辑、收藏和删除记录。

## 数据与备份

个人添加的公式和收藏保存在当前浏览器的本地存储中，不会自动同步到 GitHub。请使用程序中的“导出备份”定期保存数据；更换文件位置、浏览器或电脑前，先导出备份，再在新位置导入。

本仓库只包含内置公式和说明文件，不含浏览器中的个人数据。补充包是旧版程序的增量导入文件；当前 `index.html` 已包含这些内容，无需重复导入。

## 后续添加与维护

日常添加公式可以直接使用页面中的“添加公式”功能，也可以导入程序导出的 JSON 文件。新增公式时请注明适用条件、符号含义和例题，避免把带条件的公式当作无条件结论。

开发维护直接编辑 `index.html`：页面样式、交互和内置公式均在该文件内；应用代码位于 `app-code` 脚本中。修改内置条目时应保持已有编号稳定，并检查旧版数据升级后是否仍保留用户修改。

## 核查与依赖

当前版本完成了公式逐条复核、425 条数学排版检查、2069 次数值检查，以及查询、编辑、导入导出和旧版数据升级检查。数值检查覆盖部分代表性情形，不能替代适用条件和数学证明；详细范围见核查报告。

使用 KaTeX 0.18.7 进行数学排版，其 MIT 许可已嵌入 HTML，并另外保存在 `licenses/` 中。程序用于查询和编辑公式，不自动求解或计算结果。
